# Pranav Raj · Agent Console

Observability-style portfolio (dark `#0B0D10`, electric blue accent, monospace metadata).

## Develop

```bash
npm install
npm run dev
```

## Content

- `src/data/caseStudies.ts` — Lyzr case studies (verdict bars, activity logs, graphs)
- `src/data/projects.ts` — GitHub artifact links
- `src/data/resume.ts` — experience, profile, education

## Build

```bash
npm run build
```
